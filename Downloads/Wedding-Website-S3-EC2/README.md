# Wedding Gallery Website using AWS EC2 and Amazon S3

## Project Overview

This project hosts a static Wedding Gallery website on an Amazon EC2 instance. The wedding photos are stored in an Amazon S3 bucket and displayed on the website using S3 Object URLs.

## AWS Services Used

- Amazon EC2
- Amazon S3
- Apache Web Server

## Architecture

User
↓
EC2 (Apache Web Server)
↓
HTML Website
↓
S3 Object URLs
↓
Wedding Images

## Steps Performed

1. Created an S3 bucket.
2. Uploaded 5 wedding images.
3. Made the images publicly accessible.
4. Launched an Ubuntu EC2 instance.
5. Installed Apache Web Server.
6. Created a static HTML website.
7. Connected S3 Object URLs to the website.
8. Hosted the website on EC2.

## Website Features

- Responsive image gallery
- Images loaded directly from Amazon S3
- Static website hosted on EC2
- Simple HTML and CSS
